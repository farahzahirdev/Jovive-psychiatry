# Jovive Psychiatry Landing Page

Marketing landing page for [Jovive Psychiatry](https://jovivepsychiatry.com/) — personalized mental health care with therapy, medication management, and BrainsWay TMS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- Conversion-focused page: hero, services, why Jovive, TMS spotlight, locations, Vituity trust, booking calendar, and inquiry form
- Primary CTAs: Book your Free Consultation, Call (925) 248-3432
- Secondary CTA: Find out if you Qualify
- Embedded 4TMS calendar + inquiry form
- Brand fonts (Louize / Basetica) and logo orange (#F47B20)

## Deploy

```bash
npm run build
npm start
```

Deploy on [Vercel](https://vercel.com) or any Next.js-compatible host.
